# WiFi Edge Node

## Project

WiFi-based edge telemetry node for polyhouse mushroom cultivation.

## Purpose

Collect environmental data such as:

- Temperature
- Humidity
- CO₂

and transmit to cloud services for monitoring.

## Hardware

Board: ESP32 WROOM-32D

## Reason for Selection

ESP32 provides:

- Dual-core processor
- More RAM
- Better TLS support
- Bluetooth capability
- Multiple ADC channels

making it suitable for MQTT-based secure telemetry systems.
